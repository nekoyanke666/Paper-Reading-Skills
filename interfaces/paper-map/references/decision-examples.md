# Decision Examples and Expected Outcomes

These examples specify behavior, not paper facts. Check identity and evidence before applying an operation rather than matching wording mechanically.

## First construction

With traceable sources, root the main view in the core research question and select necessary premises, methods/arguments, findings/claims, and limits. Use concise names and full detail in the sidebar. Every edge reads as a meaningful proposition with justified direction. Give details requiring another question their own view connected by shared nodes.

With only an abstract, label scope and provisional/partial profile/model explicitly. Do not draw inferred experiments or mechanisms as findings. While language is pending, sources/model work may proceed, but do not publish guessed-language content.

## Three phrasings of one edge

If X → supports → Y already exists and new wording says “X provides evidence for Y,” reuse supports, endpoints, qualifiers, and edge ID; add sources/explanation. Do not create a “provides evidence” type or duplicate. A different object or time needs identity/qualifier review before merging. A translated display name is still the same predicate.

## Association and causality

Co-variation of A and B alone uses associated_with, with measurements, limits, and alternatives. It does not become promotes. A later intervention may support a new scoped causal proposition after alternative explanations are assessed: preserve the observational relation/history and add the appropriate causal relation with causalBasis, not merely rename an edge more confidently.

A proposed negative-feedback mechanism may combine hypothetical inhibition and promotion into a cycle. The T marker describes negative effect; dashes describe uncertainty. Both may apply.

## Rename, clarify, or distinguish

A more precise name for the same receptor updates its node in place, retaining ID/positions and old-name aliases. Search both names and update all views. Total protein and active protein may need separate nodes when the study distinguishes measurements/states; concise labels must not erase the distinction. A repeated definition question may require no map change.

## Extend or split

A question about intermediate concept C can extend near C or create a focused tree rooted at the same C ID. Show its shared marker and sidebar route back. A fifth predicate type triggers meaningful separation of mechanism, evidence, or methods with shared nodes; do not rename everything as association or count synonymous names as separate types.

## Correct, remove, merge, and restore

Retain a refuted claim and its evidence with clear correction/status/limits; inspect all dependent relationships rather than erasing history. To simplify the main tree, move detail to a sensible connected view without removing shared content elsewhere.

For confirmed duplicates, merge into a chosen target, preserve redirects/reasons, reconnect and deduplicate. Resolve accidental self-edges or support conflicts before committing rather than silently discarding them. Retire mistakenly added out-of-scope artifacts only after explicit root/edge handling, preserving originals. Restore with the original identity/reason; merged IDs do not reappear as copies.

## Language and translation preferences

If fullTranslation is No, keep full-document progress skipped-by-preference while figure explanation and questions use the chosen language. A request to translate one passage does not enable a full document automatically. Changing the session language retains graph identities and sources, versions localized terms/UI and translation artifacts, and rechecks label geometry.

## Acceptance

The same canonical session and locked versions rebuild to identical bytes. A new concept does not arbitrarily move old nodes. Search, sharing, and details resolve the same objects. Without a real browser, report structural/runtime checks only and leave visual QA unperformed; fictional fixtures do not establish real-paper interpretation quality.

# Faithful Content, Source-Like Pages and Sentence Anchors

Read for full, continued or local translation. The deliverable is a faithful translated counterpart of the requested source, not a teaching manuscript or rewritten summary. Preserve the authors' content and reading order; target-language grammar may change without changing the scientific meaning.

## Establish stable source units

Inventory physical PDF/page index and any printed page label, page regions/columns, logical paragraphs and sentence boundaries. Distinguish physical page position from a printed journal page number so citations remain unambiguous. Give each text unit a stable source ID plus page/region/paragraph/sentence locator and a matching translated range.

Reconstruct multicolumn reading order from the actual page. PDF line breaks, column wraps and end-of-line hyphenation do not automatically create new sentences or paragraphs. Respect real headings, paragraph breaks, equations, list items, table cells and captions rather than flattening everything into prose. Abbreviations, decimal points and mathematical punctuation are not necessarily sentence endings.

Use source pages and complete logical paragraph/sentence units to decide translation batches and their starting points. Save the exact next untranslated locator. When a sentence/paragraph crosses a page, record its start/end pages and continuation rather than splitting away a premise or repeating text. One source sentence may naturally require more than one target sentence; retain explicit mapping instead of inventing a strict punctuation identity.

## Keep the translated content equivalent

Cover every requested source unit exactly once, preserving its assertions, comparisons, conditions, scope, uncertainty, negation, quantities, citations, symbols and references. Do not omit difficult passages, compress methods into a summary, add explanatory examples or import a narrative skill's new headings/transitions. Translate the existing figure captions, not an assistant-authored account of what the image means.

Preserve source heading levels and source order. Minimal clearly labeled translator notes can record genuine ambiguity, illegibility or a necessary terminology choice; keep them outside author text and proportionate. Important translated terminology retains verified adjacent English names as required by the shared terminology contract. Such lookup labels do not authorize new scientific claims.

## Choose a layout that supports correspondence

Default to a target-language main document with the original file/pages retained for parallel lookup. When useful, provide a separate bilingual comparison view/file keyed by the same source units, rather than inserting a second full copy of every paragraph and image into a layout-matched main version. The agent makes this bilingual presentation choice without asking another optional question; explicit user choices take precedence.

Use the original page as the composition template: page size, margins, column structure and reading direction, headings, figure/table/equation/caption positions, spacing hierarchy and scientific notation. Keep the same authentic scientific graphics, localizing their text faithfully under the figure-unit contract. Associate each caption with its actual figure. Do not move a floating figure to its first textual mention merely because that would suit a teaching narrative.

For a PDF source and an unspecified output format, prefer a paged rendered translation with an editable source and saved alignment map when tools permit; otherwise use clearly separated source-page sections in a document/HTML format. Use appropriate available document/PDF tools, render and compare the result with the source. Plain text with page labels alone is not proof that source layout was reproduced.

Translation length and target-language typography can change line/page breaks. Preserve content, scientific image detail and readable text before exact box fitting. Adjust whitespace and local flow where possible; if extra target pages or figure/caption continuation are necessary, map them clearly to source pages and record the deviation. Do not delete words, distort data or shrink type to unreadability to claim identical layout. Use locators in metadata, bookmarks or an alignment view rather than adding administrative prose to the article body.

## Audit coverage and resume

Compare the requested source units with translated units for omissions, duplicates, order and source-version mismatches. Check the actual figure/caption association, visual-label coverage, numbers/equations/citations, asset links, page/column order, overflow and legibility in the rendered output. Source-page correspondence, faithful meaning and visual-layout similarity are separate checks; report what was actually verified.

Save source-unit boundaries, translated ranges, page mapping, presentation choice, gaps and the exact next paragraph/sentence locator under progress.translation. Reuse unchanged verified translation and figures. A layout correction or missing-image repair does not require retranslating valid text, and a completed text range does not establish missing visual or layout completion. Preserve prior outputs/revisions rather than silently relabeling them as a faithful new version.
